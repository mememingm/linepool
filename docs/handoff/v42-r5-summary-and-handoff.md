## 1. 已确定的架构，不再重新讨论

- LP、ONCE 是两个网站；共享同一份核心代码，分别运行后端和逻辑数据库。用户、会话、订单、钱包、流水独立，同邮箱不合并，不做跨站 SSO。
- 每站一个自营 PC 连接，每个代理一个自有 PC 连接。代理使用可信 PinClode 身份登录，可查看本连接号码、验证码、能力和套餐配置。
- 代理自行销售，平台不经手代理销售款。旧批发、进货余额、分货、结算写入停用，历史表和必要读取保留。代理客户/买家站内交易功能继续搁置。
- 自营消费使用本站积分钱包；LP 按平台接码，ONCE 整号租赁。自营收信按真实使用期间归属，代理按连接所有权取码，不伪造客户订单或期间。
- 每站 API 与 worker 分进程；上游号码和消息由 worker 拉取，用户查询读本地。PC 买号、上游续期和划拨不由本站自动执行。
- 当前只使用 Mock。未接真实 PC、支付、SIP 或邮箱；近期不做现金退款，不新增支付渠道三表、积分来源批次/分摊、跨站租户平台或白标站群。

依据顺序：用户最新明确指令 → 总文档当前决定及授权 → 已修订专题设计 → 未冲突的历史资料。旧 S1–S8、旧 S4 worktree 和旧交接只能用于定位历史，不能恢复跨站合并或代理分销交易方案。
